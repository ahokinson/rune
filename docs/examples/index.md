## `examples/shared/`

Code shared across examples but **not** engine-level — reusable game-side utilities you'd copy into your own project, not import from `rune`:

- `particles.ts` — `emitter`, a manual-emit [`Particles`](../api/Class.Particles.md) factory (`ratePerSecond` 0, so nothing spawns until `.emit(n)` fires on a gameplay event) parked at an origin the owner repositions each frame. Used by `overworld`, `tamagotui`, and `tomb` so muzzle flashes, blood spray, coin sparkles, brick shatter, and mood FX all get constructed identically.
- `overlay.ts` — the screen-overlay widget kit: `drawPanel`, `drawBar`, `drawGauge`, `drawSparkline`, `drawTicker`, `scrambleReveal`, `drawBigText`/`measureBigText`. Cell-by-cell canvas drawing that composites with the scene and respects whatever palette the caller drives. Used by `attack-surface` and `tamagotui`.
- `textures.ts` — `makeMarbleTexture`, a procedural veined-marble `Texture` built on the engine's [`Noise3D`](../api/Class.Noise3D.md). The general debug textures ([`checkerTexture`](../api/Function.checkerTexture.md), [`uvGridTexture`](../api/Function.uvGridTexture.md)) live in the engine; marble stays here because it's an art look specific to the teapot demo. Used by `teapot`.
